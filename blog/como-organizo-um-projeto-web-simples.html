Como organizo um projeto web simples

Para um portfolio ou blog pequeno, uma estrutura manual com HTML e CSS pode ser suficiente, rapida e facil de manter.

30/06/2026

Nem todo projeto precisa comecar com framework, banco de dados ou painel administrativo. Quando o objetivo e publicar paginas estaticas com bom visual e boa leitura, HTML por pagina pode resolver muito bem.

Estrutura basica

Uma organizacao simples separa a pagina principal, a listagem do blog, os artigos e os arquivos compartilhados. 

/index.html
/blog.html
/blog/
  meu-artigo.html
/assets/
/style.css

Por que funciona

Essa estrutura e direta, leve para hospedar e boa para SEO. Cada artigo tem sua propria URL, titulo, descricao e conteudo independente.

Quando evoluir

Se o blog crescer muito, ai vale pensar em Markdown, gerador estatico ou algum CMS. Para comecar, o manual entrega mais rapido e evita complexidade desnecessaria.
